Herramientas

Comparar dos fechas (Sentinel-2)▾
Conecta tu cuenta Sentinel Hub en Ajustes para usar esta herramienta.
La fecha A es la que tengas puesta ahora mismo en "Sentinel-2 (fecha exacta)" como capa base. Elige aquí una fecha B distinta.
Medir distancia y área▾
Toca puntos sobre el mapa para trazar una línea. Con 3 puntos o más también calcula el área.
Pronóstico puntual (Windy)▾
Añade tu clave de Point Forecast en Ajustes para usar esta herramienta.
Animación de nubes▾
Cambia la capa base a "MODIS Terra" o "VIIRS SNPP" para usar esta herramienta.
Precarga cada día antes de mostrarlo, así siempre ves el fotograma completo, no a medio cargar. La velocidad es un mínimo — si la red va lenta, espera lo que haga falta en vez de mostrar huecos.
